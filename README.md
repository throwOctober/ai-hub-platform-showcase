# AI Hub Platform｜支持受控自进化的 AI 教育中台

> **把做过的任务，变成下一次可复用的能力。**

AI Hub 的技术内核是可复用技能及其执行体系。平台既能把知识检索、内容生成和来源标注组合为可接管的任务流程，也具备按需启用的技能自进化和评测驱动优化：从任务经验提出新技能，从样例评测提出提示改进，让能力建设有积累、有依据，也由人工决定是否接纳改进候选。

*AI education platform with human-reviewed skill evolution, evaluation-driven prompt optimization and reusable teaching workflows.*

## 核心机制

| 核心 | 如何工作 | 带来的价值 |
| --- | --- | --- |
| **受控技能自进化** | 从成功的多步任务中提炼可复用技能候选，经过质量过滤、判重和人工审核后，可按组织配置纳入后续任务。人工拒绝的候选为后续提取提供负例参考。 | 把执行经验转成可审核的能力资产，减少只停留在单次结果上的积累。 |
| **评测驱动的提示优化** | 用整理好的样例建立基线，针对低分案例反思并增量改写，再用同一组样例比较，筛出符合改进条件的候选。 | 让提示策略的改进有对照依据，供人工比较和选择。 |
| **可接管的技能编排** | 技能组合成有状态流程，支持分步确认、编辑、返回和检查点续跑；章节重生成会处理受影响的下游结果。 | 把长任务拆成能复用、能干预的执行单元，保留教师的内容判断。 |
| **模型分工与来源追溯** | 可按技能复杂度选择已配置模型；知识检索进入生成过程，生成段落可关联来源片段、定位与匹配信息。 | 为不同任务配置执行策略，并为内容复核保留可查看的来源依据。 |

## 自进化具体做什么

**路径一：任务经验 → 新技能候选**  
多步任务完成 → 提炼通用模式 → 质量与重复过滤 → 候选池 → 人工审核 → 按组织配置供后续任务复用

**路径二：评测样例 → 提示改进候选**  
基线评测 → 分析低分样例 → 增量改写 → 同样例复测 → 筛选改进候选 → 人工审阅差异

两条路径分别完成技能沉淀与提示优化。演进对象是**技能配置与提示模板**；提示优化由平台管理员触发，当前产物是供人工审阅的候选与差异。

技能提炼与复杂度路由默认关闭，按组织授权启用；提示优化需另行启用相应功能，并由平台管理员触发。来源匹配供人工核查，不构成内容必然正确的保证。

## 条件与范围

- **内容审核**：生成、评阅与科研辅助结果需要人工检查。
- **服务依赖**：模型、知识解析、检索和媒体渲染需相应配置。
- **展示范围**：科研等拓展模块按环境开通，不承诺发表或教学成效。

功能可用性与模型服务、知识解析和媒体资源配置有关，具体条件见演示资料。
