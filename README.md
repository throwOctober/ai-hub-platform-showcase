# AI Hub Platform｜受控自进化的AI中台与教学资产生成

> **让课程、实训、判题与多模态资源有可复用的生成流程，让任务经验成为可审核的能力候选。**

AI Hub 面向教师、课程建设团队与教育 AI 开发者，将**受控技能自进化、可接管的技能编排与教学资产生成**连接起来。课程结构与正文、实训指导书、判题规则和测试用例、环境规格、图片与课件媒体分别拥有自己的生成或配置路径，使用者保留编辑、核查与采用决定。

*AI platform for human-reviewed skill evolution and teaching assets: courses, lab guides, judging-rule and test-case candidates, environment specifications, illustrations, editable slides, narration and captioned lecture videos.*

## 首先了解三个特色

1. **受控自进化**从成功的多步任务提炼技能候选，审核通过后按组织配置复用。提示优化使用同一组样例比较候选，由管理员审阅差异。
2. **实训资产生成**把教学要求转成实训指导书、判题规则、检查脚本、测试用例候选和步骤检查点，供教师审查采用。环境规格可管理镜像引用、依赖和初始化要求。
3. **多模态教学资源**围绕课程或指导书生成插图、可编辑 PPT 和语音旁白，并可将课件画面、旁白与字幕合成视频。

## 生成和配置的五类产物

| 资产 | 输入与产出 | 审核和使用条件 |
| --- | --- | --- |

## 自进化如何积累能力

**任务经验 → 技能候选**：多步任务完成 → 提炼通用模式 → 质量与重复过滤 → 候选池 → 人工审核 → 按组织配置复用。拒绝候选为后续提炼提供负例参考。

**评测样例 → 提示候选**：建立基线 → 分析低分案例 → 增量改写 → 同样例复测 → 比较改进候选 → 人工审阅差异。

两条路径分别沉淀技能和改进提示，演进对象是**技能配置与提示模板**。技能提炼与复杂度路由默认关闭，按组织授权启用。提示优化另行启用，由管理员触发并审阅候选提示的差异。

## 技能编排与来源依据

- **人工接管与检查点**：分步确认、编辑、返回和续跑；修改上游内容后处理受影响的下游结果。
- **RAG 知识库问答与来源追溯**：已解析授权资料参与检索和生成，已有引用可回到来源片段核查；匹配信息不保证事实正确。
- **知识图谱与课程关系**：组织知识点、课程结构与相关路径，辅助理解课程内容。
- **可选模型分工**：按技能复杂度选择已配置模型，需相应组织与功能授权。

## 一个实训资源准备场景

教师提供目标与授权资料 → 生成课程内容和实训指导 → 形成检查/判题候选 → 核对环境规格、镜像引用与判据 → 在执行平台配置并验证 → 按需形成课件、旁白和字幕视频。

这是一种资源准备示例。教师按任务选择各项能力并审查产物，由执行平台完成环境创建和运行验证。

## 其他教学与科研模块

智能备课、实验指导、题库与评阅建议、科研资料整理、大纲与起草、教学记录回顾，以及角色权限、用量和预算管理共同支持教学工作。科研和图谱等模块按环境开通，生成与分析结果需人工检查，不承诺发表或教学成效。
