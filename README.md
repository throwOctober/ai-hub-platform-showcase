# AI Hub Platform｜可审改、可追溯的 AI 教学中台

> **让教学资源可以继续加工，让 AI 辅助有依据、可复核。**

面向院校教学团队，AI Hub 把课程资料、内容生成与教师审改组织在同一工作平台中。教师可以分步生成和修改课程、教案与课件，围绕已解析的授权资料备课和答疑，核对已有引用；评阅保留评分建议与教师确认记录，管理员统一配置模型、权限和用量。生成结果可以继续修订，教学判断仍由教师掌握。

*An AI teaching workspace for editable course resources, source-aware assistance, teacher-reviewed assessment and managed model access.*

## 四个值得关注的特点

| 特点 | 具体做法 | 带来的价值 |
| --- | --- | --- |
| **教学内容可继续加工** | 按步骤生成课程，编辑章节、调整教案和课件，必要时重新生成选定内容。 | 教师能把生成草稿改成适合本课程的材料，并继续积累和修订。 |
| **围绕课程资料工作** | 授权资料完成解析后用于相关生成与检索答疑，在已有引用中核对来源。 | 把讨论放回课程资料上下文，便于检查内容依据和资料覆盖范围。 |
| **评阅保留教师判断** | 展示评分维度和建议，区分 AI 结果与教师确认分数，保留改分理由和操作记录。 | 为讲评、调整和复核保留过程依据。 |
| **AI 使用纳入统一管理** | 配置模型、角色权限、用量配额和提示词模板。 | 让教学团队共享能力，同时明确谁能使用、资源如何分配。 |

## 适合怎样的教学工作

- 课程负责人：从已有资料和教学目标出发，分步建设课程、教案与课件。
- 授课教师：围绕课程资料开展答疑、出题与评阅，并确认最终教学内容。
- 教学管理者：统一配置模型、角色权限、用量配额与提示词模板。

## 实践流程

准备授权课程资料 → 分步生成与编辑 → 检索答疑或教学评阅 → 教师核对、确认与修订

## 条件与范围

- **内容审核**：生成、评阅与科研辅助结果需要人工检查。
- **服务依赖**：模型、知识解析、检索和媒体渲染需相应配置。
- **展示范围**：科研等拓展模块按环境开通，不承诺发表或教学成效。

功能可用性与模型服务、知识解析和媒体资源配置有关，具体条件见演示资料。
